Temeljni gradniki programa

Vsak program v Javi ima enako ogrodje: razred, metodo main, spremenljivke, izpis in vnos. Spoznaš osem primitivnih tipov in kako ločiš med njimi, aritmetične operatorje ter prve primere vejitve in zanke. Pogoje in zanke natančno obravnavata poglavji 5 in 6.

Razlaga 1

Struktura programa

Program v Javi je zapisan v razredu. Izvajanje se začne v metodi main, stavki pa se izvajajo drug za drugim, od zgoraj navzdol. To je zaporedje, prvi od treh gradnikov programa.

import java.util.Scanner;     // knjižnica (samo kadar jo potrebujemo)

/* Najmanjši program:
   izpiše pozdrav. */
public class Main {
    public static void main(String[] args) {
        // izpis na zaslon
        System.out.println("Pozdrav");
    }
}

Razlaga 2

Spremenljivke in primitivni tipi

Spremenljivka je poimenovano mesto v pomnilniku, kamor shranimo podatek. Java je strogo tipizirana: vsaka spremenljivka ima tip, ki ga zapišemo ob deklaraciji in se ne more spremeniti. Tip določa, kakšne vrednosti lahko shranimo.

int starost;            // deklaracija: tip in ime
starost = 17;           // prireditev: = pomeni »shrani v«
double visina = 1.68;   // deklaracija z začetno vrednostjo (inicializacija)
final double PI = 3.14159;   // konstanta: vrednosti ne moremo več spremeniti

Ime spremenljivke sestavljajo črke, števke, _ in $. Ne sme se začeti s števko, ne sme vsebovati presledkov ali znakov, kot je @, in ne sme biti ključna beseda. Po dogovoru pišemo steviloDijakov (z malo začetnico, naslednje besede z veliko). Lokalna spremenljivka mora dobiti vrednost, preden jo preberemo.

Osem primitivnih tipov

String ni primitiven tip. String je razred (zato velika začetnica). Besedilo pišemo v dvojnih narekovajih: String ime = "Ana";. Pazi na razliko: 'A' je char, "A" je String.
Realna števila so privzeto double. Zapis 3.14 je tipa double, zato float f = 3.14; ne gre. Zapisati moraš 3.14f. Podobno velja za long: velike vrednosti dobijo črko L.

Kako se vrednosti med tipi pretvarjajo (npr. int v double), kaj je prekoračitev območja in kako uporabljamo razrede Integer in Double, spoznaš v poglavju 4.

Razlaga 3

      
Izpis na standardni izhod

      

        
System.out.println(...) izpiše vrednost in preskoči v novo vrstico. System.out.print(...) izpiše vrednost in ostane v isti vrstici. Izpišemo lahko vrednost katerega koli tipa.

      

      
int a = 1, b = 2;
System.out.print("a");                  // a
System.out.println("b");                // b in nova vrstica
System.out.println(a + b);              // 3     (števili se seštejeta)
System.out.println("vsota: " + a + b);  // vsota: 12   (po vrsti od leve: besedilo + 1, nato + 2)
System.out.println("vsota: " + (a + b)); // vsota: 3   (oklepaj najprej izračuna 1 + 2)
System.out.println(7 / 2.0);            // 3.5   (double se izpiše z decimalno piko)

      
Operator + združuje besedilo, če je vsaj eden od operandov niz. Izraz se računa od leve proti desni, zato se pri 1 + 2 + "a" števili najprej seštejeta (rezultat 3a), pri "a" + 1 + 2 pa se združujeta kot besedilo (a12).

      
Posebni znaki v besedilu zapišemo z leva poševnico: \n nova vrstica, \t tabulator, \" dvojni narekovaj, \\ poševnica.

      
Oblikovan izpis s printf: v besedilo vstavimo označbe za vrednosti, ki sledijo.

      

        
System.out.printf("%d%n", 42);              // 42
System.out.printf("%.2f%n", 1.23456);       // 1.23
System.out.printf("%s je star %d let%n", "Ana", 17);
System.out.printf("Ocena: %c%n", 'A');

Pozor 1: nextInt() in nextLine(). nextInt() prebere samo število in pusti znak za novo vrstico. Naslednji nextLine() zato vrne prazen niz. Pred nextLine() dodaj še en klic sc.nextLine();, ki ostanek vrstice zavrže.

Z sc.useLocale(Locale.US); (import java.util.Locale;) vedno velja pika. Če vnos ne ustreza tipu (npr. beseda namesto števila), se sproži izjema InputMismatchException (poglavje 10).

Prioriteta: najprej *, /, %, nato +, -; enako močni operatorji se izvajajo od leve proti desni; oklepaji imajo prednost. Pri 1 + 2 * 3 - 4 / 5 je najprej 2 * 3 = 6 in 4 / 5 = 0, rezultat je 7.

        
Celoštevilsko deljenje (int / int) odreže decimalni del proti nič: -7 / 2 je -3. Ostanek ima predznak deljenca: -7 % 2 je -1. Realni rezultat dobimo, če je vsaj eden od operandov double: 5 / 2.0.
