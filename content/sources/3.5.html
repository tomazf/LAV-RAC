Pogojni stavki v Javi

Program se mora pogosto odločiti, kaj bo naredil: izpisati »sodo« ali »liho«, izbrati oceno glede na točke ali ime dneva glede na številko. Spoznaš stavek if z vejo else, gnezdenje in verige else if, pogojni operator in stavek switch.

if·else·switch trije gradniki vejitve
Razlaga 1

Pogojni stavek if

Pogojni stavek uporabimo, kadar želimo nek stavek izvesti samo takrat, ko je izpolnjen pogoj. Zapišemo ga z besedo if, za njo v oklepaju pogoj, nato stavek, ki se izvede, če ima pogoj vrednost true.

Pogoj je vedno izraz tipa boolean: primerjava (x < 0, n % 2 == 0), logična spremenljivka ali več pogojev, povezanih z &&, || in ! (poglavje 4).

if (pogoj) stavek;

// primer: absolutna vrednost
int x = -7;
if (x < 0) x = -x;      // predznak spremenimo samo pri negativnem številu
System.out.println(x);   // 7
Kaj želimo preveritiPogoj v Javi
x je negativenx < 0
n je sodo številon % 2 == 0
a leži na intervalu [20, 40]a >= 20 && a <= 40
a leži zunaj intervala [20, 40]a < 20 || a > 40
x je večkratnik yx % y == 0
niza s in t imata enako vsebinos.equals(t)

Pozor: zapisa 20 <= a <= 40 Java ne pozna. Prvi del da true ali false, logične vrednosti pa ne moremo primerjati s številom 40. Pravilno: a >= 20 && a <= 40.

Razlaga 2

      
if – else in blok stavkov

      

        
Če želimo v primeru, ko pogoj ni izpolnjen, izvesti kakšen drug stavek, dodamo besedo else in stavek za ta primer. Izvede se natanko ena od obeh vej.

        
Kadar mora veja vsebovati več stavkov, jih obdamo z zavitimi oklepaji { }. Tak stavek imenujemo sestavljeni stavek ali blok.

      

      

        
int n = 7;
if (n % 2 == 0) {
    System.out.println("sodo");
    n = n / 2;
}
else {
    System.out.println("liho");
    n = 3 * n + 1;
}
System.out.println(n);   // liho, nato 22

        
      

      
Brez zavitih oklepajev k pogoju spada samo prvi stavek. Pri if (a > 5) a = a * 2; a = a + 1; se drugi stavek izvede vedno, ne glede na pogoj. Zamik vrstic na to ne vpliva. Zato zavite oklepaje pišemo tudi pri enem stavku.

      
Doseg spremenljivk v bloku

      

        
Spremenljivka, ki jo deklariramo znotraj bloka, velja samo do konca tega bloka. Izven bloka je ni (kot da ne obstaja), zato se program, ki jo uporabi za blokom, ne prevede.

      

      
int x = 7;
if (x > 0) {
    int dvojno = 2 * x;           // dvojno obstaja samo v tem bloku
    System.out.println(dvojno);   // 14
}
// System.out.println(dvojno);   // napaka pri prevajanju: cannot find symbol

int z;                            // spremenljivko deklariramo PRED vejitvijo,
if (x < 10) z = 1; else z = 2;    // v obeh vejah ji določimo vrednost
System.out.println(z);            // 1

Razlaga 3

      
Gnezdenje in »viseči« else

      

        
Pogojni stavek je navaden stavek, zato ga lahko zapišemo znotraj drugega pogojnega stavka. Temu rečemo gnezdenje. Notranji pogoj se preverja samo, če je zunanji izpolnjen.

        
Težava nastane, če napišemo dva pogojna stavka in samo en else. Pravilo prevajalnika je jasno: else pripada zadnjemu (najbližjemu) stavku if, ki še nima svojega else. Zamik vrstic tega ne spremeni.

      

      

        

          Zamik zavaja
          
if (pogoj1)
    if (pogoj2) stavek1;
else stavek2;     // pripada if (pogoj2)!

        

        

          else pripada prvemu if
          
if (pogoj1) {
    if (pogoj2) stavek1;
}
else stavek2;     // zdaj pripada if (pogoj1)

        

      

      
int x = 5, y = -3;
if (x > 2) {
    x = 3;                 // izvede se, ker je 5 > 2
    if (y < 0) {
        x += 1;            // izvede se, ker je -3 < 0
        y++;
    }
}
System.out.println(x + " " + y);   // 4 -2

      
Pri maturitetnih nalogah »izračunaj vrednost spremenljivk« si zapiši vrednosti po vsakem stavku. Najprej preveri zunanji pogoj: če ni izpolnjen, se celoten notranji del preskoči.

Razlaga 4

      
Veriga else if in pogojni operator

      

        
Kadar je možnosti več kot dve, uporabimo posebno obliko gnezdenja: za vsakim else takoj sledi nov if. Pogoji se preverjajo od zgoraj navzdol. Izvede se veja prvega izpolnjenega pogoja, ostali se ne preverjajo več. Zadnji else velja za vse ostale primere.

      

      

        
int tocke = 72;
if (tocke >= 90) {
    System.out.println("odlicno");
} else if (tocke >= 50) {
    System.out.println("pozitivno");
} else {
    System.out.println("negativno");
}
// izpis: pozitivno

        
      

      
Vrstni red pogojev je pomemben. Če bi najprej preverili tocke >= 50, bi 95 točk dobilo »pozitivno«, ker je ta pogoj izpolnjen prvi, »odlicno« pa ne bi bilo nikoli izbrano. Pri mejah »vsaj« začnemo pri največji meji.

      
Pogojni operator ?: namesto if – else

      

        
Kadar if – else le izbere eno od dveh vrednosti za isto spremenljivko, ga lahko zapišemo krajše s pogojnim (ternarnim) operatorjem: pogoj ? vrednost1 : vrednost2. Spodnja programa izpišeta enako.

      

      

        
int x = 7;
int y = 8;
int z;
if (x < y) {
    z = x;
}
else {
    z = y;
}
System.out.println(z);   // 7

        
int x = 7;
int y = 8;
int z = (x < y) ? x : y;
System.out.println(z);   // 7

      

      
Pogojni operator vrne vrednost, ne izvaja stavkov. Za izbiro med dvema izpisoma ali dvema skupinama stavkov uporabi if – else.

Razlaga 5

      
Stavek switch

      

        
Stavek switch izračuna vrednost izraza in skoči na oznako case z enako vrednostjo. Če take oznake ni, skoči na default (če obstaja). Primeren je, kadar isto spremenljivko primerjamo z več konkretnimi vrednostmi.

      

      
switch (izraz) {
    case vrednost1: stavek1; break;
    case vrednost2: stavek2; break;
    case vrednost3: stavek3; break;
    default:        stavekD;
}

      

        
DelPomen

        
          
switch (izraz)začetek stavka; izraz je tipa byte, short, char ali int (od Jave 7 tudi String). long, double, float in boolean niso dovoljeni.

          
case vrednost:oznaka možnosti; vrednost mora biti konstanta, ne pogoj (case x > 5: ni dovoljen)

          
breakzaključi možnost in takoj prekine izvajanje stavka switch

          
default:izvede se, če nobena oznaka case ni enaka izrazu

        
      

      
Brez break se izvajanje nadaljuje

      

        
Ko switch skoči na ustrezno oznako, izvaja stavke do prvega break ali do konca stavka switch. Oznake case, ki sledijo, ga ne ustavijo. To je pogosta maturitetna past, lahko pa ga uporabimo tudi namenoma, ko ima več vrednosti enak rezultat.

      

      

        
char ch = 'b';
switch (ch) {
    case 'a': System.out.print(ch);
    case 'b': System.out.print(ch);   // skok sem
    case 'c': System.out.print(ch);   // nadaljuje
    case 'd': System.out.print(ch);   // nadaljuje
}
// izpis: bbb

        
int mesec = 4;
int dni;
switch (mesec) {
    case 2:
        dni = 28;
        break;
    case 4: case 6: case 9: case 11:
        dni = 30;                      // več oznak, en rezultat
        break;
    default:
        dni = 31;
}
System.out.println(dni);              // 30

      

      
Pretvorba if v switch

      

        
Verigo if – else if lahko pretvorimo v switch, kadar vsi pogoji primerjajo isto spremenljivko z enakostjo (==) s konstanto. Vsak pogoj dan == 3 postane case 3:, zadnji else postane default:, vsaka veja pa se konča z break. Pogojev z <, >, intervalov ali pogojev z več spremenljivkami ne moremo neposredno pretvoriti.

      

      

        
if (dan == 1) ime = "ponedeljek";
else if (dan == 2) ime = "torek";
else if (dan == 3) ime = "sreda";
else ime = "dan ne obstaja";

        
switch (dan) {
    case 1: ime = "ponedeljek"; break;
    case 2: ime = "torek"; break;
    case 3: ime = "sreda"; break;
    default: ime = "dan ne obstaja";
}
