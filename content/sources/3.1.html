Razlaga 1

Kaj je Java

Java je višji, objektno usmerjen programski jezik. Leta 1995 ga je izdalo podjetje Sun Microsystems, danes ga razvija Oracle skupaj s skupnostjo OpenJDK. Geslo jezika je »Write once, run anywhere«: program enkrat prevedemo in ga poganjamo na vsakem sistemu, ki ima javanski navidezni stroj.

Programske jezike delimo na nižje in višje. Nižji so blizu strojni opremi, višji so blizu človeku in neodvisni od procesorja.

Razlaga 2

Prevajanje in tolmačenje

Procesor razume samo strojno kodo. Izvorno kodo višjega jezika je treba pretvoriti, in to na dva načina:

  • Prevajalnik (compiler) prevede celoten program pred izvajanjem. Nastane nova datoteka. Če je v programu sintaktična napaka, prevod ne nastane.
  • Tolmač (interpreter) bere program med izvajanjem in vsak ukaz takoj izvede. Ločene datoteke ni. Napaka se pokaže šele, ko pride izvajanje do nje.

Pri jezikih, kot je C, sodeluje še povezovalnik (linker): prevajalnik naredi objektne datoteke, povezovalnik pa jih združi s knjižnicami v eno izvršljivo datoteko (npr. .exe).

Hitrostzelo hitropočasnejehitro (JIT)

JIT (Just-In-Time) je del JVM. Dele programa, ki se izvajajo pogosto, med izvajanjem prevede v strojno kodo in jih shrani. Zato je Java skoraj tako hitra kot C. Matura opiše JVM preprosto: bajtno kodo interpretira oziroma jo prevede v izvršno. Oba zapisa sta pravilna.

Razlaga 4

JDK, JRE in JVM

  • JVM je navidezni stroj, ki izvaja bajtno kodo. Ne prevaja izvorne kode.
  • JRE = JVM + standardne knjižnice. Za izvajanje programov je dovolj JRE.
  • JDK = JRE + razvojna orodja. Za prevajanje potrebujemo JDK, ker vsebuje javac.
  • IDE (Integrated Development Environment, integrirano razvojno okolje: Eclipse, VS Code, IntelliJ, NetBeans) je programsko okolje za razvoj in preizkušanje programov: urejevalnik, gumb »Run«, razhroščevalnik. V ozadju kliče javac in java iz nameščenega JDK. Na maturi je »programsko okolje, namenjeno razvoju in preizkušanju programov« prav IDE.

Oracle od Jave 11 ne izdaja več ločenega JRE (nekateri drugi ponudniki ga še), zato običajno namestimo kar JDK. Na maturi velja klasični model: JDK ⊃ JRE ⊃ JVM.

Pravila, ki jih matura rada preverja

  • Javni razred public class Primer mora biti v datoteki Primer.java, sicer javac javi napako.
  • Java razlikuje velike in male črke: system.out ni isto kot System.out.
  • Vsak razred dobi svojo datoteko .class. Če sta v Dva.java razreda Dva in Pomocnik, nastaneta Dva.class in Pomocnik.class.
  • Program se začne v metodi public static void main(String[] args). Brez nje se prevede, ne zažene pa se. Ni je treba imeti v vsakem razredu, dovolj je v tistem, ki ga zaženemo.
  • Ključne (rezervirane) besede so besede jezika, ki jih ne smemo uporabiti za imena: class, public, static, void, int, boolean, if, for, break, extends … Besedi java in javac sta imeni ukazov, ne ključni besedi.

Razlaga 6

Kaj je v datoteki .class

Bajtna koda je zaporedje ukazov za navidezni stroj, ne za pravi procesor. Z ukazom javap -c Pozdrav vidimo, da se metoda main prevede v štiri ukaze JVM:

public static void main(java.lang.String[]);
  Code:
     0: getstatic     #7    // System.out
     3: ldc           #13   // String Pozdravljen, svet!
     5: invokevirtual #15   // PrintStream.println
     8: return

Vsaka datoteka .class se začne z »magično« številko CA FE BA BE. Nato sledi različica formata, po kateri JVM ugotovi, ali datoteko zna izvesti.

Prenosljivost in združljivost

  • Med operacijskimi sistemi: .class, preveden na Windows, teče na Linuxu in macOS brez ponovnega prevajanja. Izvorna koda ni potrebna.
  • Novejši JVM, starejša koda: program, preveden z Javo 8, teče na Javi 21.
  • Starejši JVM, novejša koda: program, preveden z Javo 21, se na Javi 8 ne zažene in javi UnsupportedClassVersionError. Pomaga javac --release 8.
  • Za primerjavo C: program.exe za Windows na Linuxu ne teče. Izvorno kodo je treba prevesti znova, z ustreznim prevajalnikom.

Sintaksa, semantika in vrste napak

Sintaksa so pravila, kako stavek zapišemo: podpičja, oklepaji, ključne besede. Semantika so pravila, kaj zapisani stavek pomeni in kaj naredi.

napaka med izvajanjem (izjema)JVM med izvajanjem; program se ustavi10 / 0 → ArithmeticException: / by zero

Ukazni javac se pri sintaktični napaki ustavi in pokaže samo njo. Druge napake (npr. nedeklarirano spremenljivko) pokaže šele, ko prvo popraviš. Eclipse prikaže vse naenkrat, zato so v nalogi M182/10 naštete tri napake.

Naloge od lažjih do težjih

Naloge z oznako Matura so iz izpitnih pol 1 iz let 2012–2026. Več jih najdeš še na strani Za doma, z enakim številom točk kot na izpitu. Naloge so dveh vrst. Pri nalogah z enoličnim odgovorom (izbira, dopolnjevanje, razvrščanje, napoved izpisa) stran odgovor preveri in podeli točke; če si pred pravilnim odgovorom ogledal rešitev, se točke ne štejejo. Pri nalogah z oznako Samoocena sam napišeš kodo (preizkusiš jo v Programizu, Eclipse ali VS Code). Stran je ne more preveriti, zato točk ni: kodo in neobvezen izpis shranimo, nato klikneš »Primerjaj z rešitvijo«, kjer vidiš svojo kodo ob primeru rešitve, prečrtaš merila in sam oceniš, ali nalogo znaš. Vrednosti so zapisane v kodi, vnosa s Scannerjem ni treba preizkušati.
