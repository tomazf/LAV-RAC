Podatkovni tipi v Javi

Vsaka vrednost v Javi ima tip, tip pa določa najmanjšo in največjo vrednost, ki jo lahko shranimo. Spoznaš, kaj se zgodi ob prekoračitvi, kako pretvarjamo med tipi, zakaj je znak char hkrati tudi število in kako iz niza dobimo število. Na koncu se naučiš brati in zapisovati izraze z operatorji, tudi s ++ in --.

območja+pretvorba+ASCII+operatorji štiri teme poglavja
Razlaga 1

Območje vrednosti in prekoračitev

Vsak primitivni tip ima končno območje vrednosti. Če rezultat pade zunaj njega, Java ne javi napake. Vrednost se »zavije« na drugi konec območja. Prevajalnik tega ne opazi, zato se težava pokaže šele v izpisu.

TipNajmanjša vrednostNajvečja vrednost
byte−128127
short−32 76832 767
int−2 147 483 6482 147 483 647 (Integer.MAX_VALUE)
long−9 223 372 036 854 775 8089 223 372 036 854 775 807
float≈ −3,4 · 10^38≈ 3,4 · 10^38 (približno 7 števk natančnosti)
double≈ −1,8 · 10^308≈ 1,8 · 10^308 (približno 15 števk natančnosti)
 
byte b = 127;
b++;                       // ni napake, vrednost se zavije
System.out.println(b);     // -128

int x = 2000000000 * 3;    // množenje int * int, rezultat je prevelik za int
System.out.println(x);     // 1705032704, ne 6000000000

Prekoračitev ne povzroči izjeme in ne napake pri prevajanju. Program se izvede, rezultat pa je napačen. Takšna napaka je semantična (poglavje 1). Če pričakuješ velika števila, uporabi long in zapiši literal s črko L.

Razlaga 2

Pretvarjanje med tipi

Vrednost enega tipa lahko shranimo v spremenljivko drugega tipa. Če gre za pretvorbo v širši tip, jo Java opravi sama (samodejna pretvorba). Če bi podatke lahko izgubili, pretvorbo zapišemo sami z oklepajem: (tip) vrednost. To se imenuje casting.

Samodejna pretvorba gre v smeri byte → short → int → long → float → double. Pretvorba iz realnega v celo število odreže decimalni del proti nič.

int a = 7;
double d = a;              // samodejno: d = 7.0
double x = 9.99;
int i = (int) x;           // ročno: i = 9 (decimalni del odpade)
int n = (int) -2.5;        // n = -2 (proti nič)
byte b = (byte) 200;       // b = -56 (prekoračitev)
System.out.println(d + " " + i + " " + n + " " + b);   // 7.0 9 -2 -56
Izraz (a = 7, b = 2, tipa int)RezultatZakaj
(double) a / b3.5pretvorba se izvede pred deljenjem
(double) (a / b)3.0najprej celoštevilsko deljenje 7 / 2 = 3, nato pretvorba
(int) 'A'65znak se pretvori v njegovo kodo

Pretvorba velja samo za izraz, v katerem je zapisana. Spremenljivka a ostane 7. Pretvorba (int) ne zaokroži: (int) 3.99 je 3. Za zaokroževanje uporabimo Math.round(3.99), ki vrne 4. Pretvorba long → float je samodejna, vendar lahko pri zelo velikih številih izgubi nekaj natančnosti.

Razlaga 3

Znak char in tabela ASCII

Spremenljivka char hrani en znak. Vsak znak ima numerično kodo. Za znake angleške abecede in številke je to koda iz tabele ASCII. Zato lahko z znaki računamo, kot da so števila.

ZnakKodaZnakKoda
' ' (presledek)32'A'65
'0'48'a'97
 
char c = 'A';
System.out.println(c);                  // A
System.out.println(c + 1);              // 66  (c se obravnava kot število)
System.out.println((char) (c + 1));     // B   (pretvorba nazaj v znak)

char d = 'd';
System.out.println(d - 'a');            // 3   (100 - 97)

char z = '7';
int cifra = z - '0';                    // 7   (številska vrednost cifre)

Za znak uporabljamo enojne narekovaje 'A', za niz dvojne "A". Rezultat c + 1 je int, zato ga za znak ponovno pretvorimo z oklepajem.

Razlaga 4

Integer, Double in pretvorba niz ↔ število

Za vsak primitivni tip obstaja ovojni razred (angl. wrapper): Integer za int, Double za double, Long, Character, Boolean. Razredi imajo uporabne metode, med njimi pretvorbo iz niza v število in nazaj.

NamenZapisRezultat
niz → intInteger.parseInt("42")42
niz → doubleDouble.parseDouble("3.5")3.5
število → nizString.valueOf(42) ali Integer.toString(42)"42"
največji intInteger.MAX_VALUE2147483647
dvojiški zapisInteger.toBinaryString(5)"101"
največji longLong.MAX_VALUE9223372036854775807
najmanjši shortShort.MIN_VALUE-32768
zaokroževanjeMath.round(2.6)3
 
String s = "425";
int n = Integer.parseInt(s);       // n je 425 (število)
System.out.println(n + 1);         // 426

String t = String.valueOf(n * 2);  // t je "850" (niz)
System.out.println(t + "!");       // 850!

Pozor: izjema. Če niz ni veljavno število, se sproži NumberFormatException (poglavje 10). Tako je pri Integer.parseInt("12a") in Integer.parseInt("3.5"). Double.parseDouble vedno zahteva piko, zato Double.parseDouble("3,5") ne deluje, ne glede na jezikovne nastavitve računalnika.

Operatorji

Operatorji so simboli, ki nad vrednostmi izvedejo operacijo. Vsak operator ima prioriteto (kaj se izvede prej) in pri enako močnih operatorjih smer računanja (večinoma od leve proti desni).

Prefiksni in postfiksni ++ in --

Prefiksni ++x najprej poveča x, nato vrne novo vrednost. Postfiksni x++ najprej vrne staro vrednost, šele nato poveča x. Enako velja za --.

int x = 5;
int a = x++;        // a = 5, x = 6   (najprej uporabi, nato poveča)
int b = ++x;        // x = 7, b = 7   (najprej poveča, nato uporabi)
int c = x-- + --x;  // c = 7 + 5 = 12, x = 5
System.out.println(a + " " + b + " " + c + " " + x);   // 5 7 12 5

Pri izrazu, v katerem se ista spremenljivka večkrat spreminja, je branje od leve proti desni težavno. V izpitnih nalogah zato vedno zapiši vrednosti po vsakem koraku.

Logični, bitni in pogojni operator

int d = 0;
if (d != 0 && 10 / d > 1) {     // 10 / d se ne izvede, ker je prvi pogoj napačen
    System.out.println("velik");
}

int n = 18;
System.out.println(~n);       // -19  (bitno negiranje: -n - 1)
System.out.println(n >> 1);   // 9    (premik v desno = deljenje z 2)
System.out.println(n << 1);   // 36   (premik v levo = množenje z 2)

int m = (n > 10) ? n * 2 : n / 2;   // m = 36 (pogojni operator)

Kratko sklenjeno vrednotenje. Pri && se druga stran ne izračuna, če je prva napačna. Pri || se druga stran ne izračuna, če je prva pravilna. Zato v d != 0 && 10 / d > 1 ne pride do deljenja z nič.

Pozor: = prireja, == primerja. Pri nizih primerjamo z equals, ne z ==. Pri + je ena od strani niz, zato se izvede združevanje besedila, ne seštevanje.
