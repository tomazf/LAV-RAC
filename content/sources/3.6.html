Zanke v Javi

Računalnik je najbolj uporaben, kadar mora isto stvar ponoviti stokrat ali milijonkrat: izpisati števila od 1 do 100, sešteti števke, poiskati praštevila. Spoznaš zanke while, for in do-while, gnezdene zanke, stavka break in continue ter vzorce, ki jih srečaš v večini nalog.

while·for·do-while tri vrste zank
Razlaga 1

Zanka while

Zanka je stavek, ki isto skupino stavkov izvede večkrat. Zanka while ponavlja stavke, dokler je izpolnjen pogoj. Pogoj je izraz tipa boolean, tak kot pri stavku if.

Pogoj se preveri pred vsako ponovitvijo, tudi pred prvo. Zato se telo zanke izvede nič-krat (če je pogoj že na začetku neresničen), enkrat ali večkrat.

int i = 1;                  // začetek
while (i <= 10) {           // pogoj
    System.out.println(i);  // telo zanke
    i++;                    // sprememba
}
// izpis: 1, 2, ..., 10

začetna vrednostpripravi spremenljivko, ki nastopa v pogoju (pred zanko)int i = 1;
pogojodloči, ali bo sledila nova ponovitevi <= 10

Neskončna zanka: če se spremenljivka iz pogoja v telesu nikoli ne spremeni (npr. pozabljen i++), pogoj ostane resničen in se program nikoli ne konča. Zavita oklepaja { } pišemo vedno: brez njiju spada v zanko samo prvi stavek.

Sledenje izvajanju zanke

Pri maturitetnih nalogah tipa »kaj izpiše« ali »kolikokrat se izvede« si pripravi tabelo: vrstica za vsako ponovitev, stolpec za vsako spremenljivko. Ne pozabi zadnjega preverjanja pogoja, ki zanko konča.

int a = 1, b = 20;
while (a < b) {
    a = a * 2;
    b = b - 3;
}
System.out.println(a + " " + b);   // 16 8

Zanka se je izvedla štirikrat. Vrednosti a in b po zadnji ponovitvi sta 16 in 8. Pri zanki, ki izpisuje, sledi tudi izpisu: izpis se zgodi samo, če se izvede telo.

Razlaga 2

Zanka for

Kadar vnaprej vemo, kolikokrat se mora zanka izvesti, uporabimo zanko for. V glavi zanke so na enem mestu zbrani začetna vrednost, pogoj in sprememba števca, ločeni s podpičji:

for (začetek; pogoj; korak) {
    telo
}

Zanka for je krajši zapis zanke while. Izvede se po vrsti: 1. začetek (samo enkrat), 2. pogoj, 3. telo, 4. korak, nato spet 2. pogoj in tako naprej. Ko pogoj postane neresničen, se zanka konča.

Zanka for
for (int i = 1; i <= 3; i++) {
    System.out.println(i);
}
Enakovredna zanka while
int i = 1;
while (i <= 3) {
    System.out.println(i);
    i++;
}

Doseg števca in prazno telo

Spremenljivka, deklarirana v glavi zanke for, obstaja samo znotraj zanke. Če vrednost števca potrebujemo tudi za zanko, ga deklariramo pred njo. Glavo zanke for lahko zapišemo tudi s praznim telesom (podpičje namesto { }). Tedaj se zanka vrti, števec pa se spreminja, dokler pogoj ne postane neresničen.

int i;                               // števec deklariran pred zanko
for (i = 10; i > 0; i -= 3);         // telo je prazen stavek
System.out.println(i);               // -2: vrednosti 10, 7, 4, 1, nato -2 ne ustreza pogoju

Za maturo: pri zanki for (int i = 0; i < n; i++) se telo izvede n-krat, števec pa ima vrednosti od 0 do n − 1. Pri i <= n bi se izvedlo (n + 1)-krat. To je najpogostejša napaka pri štetju ponovitev.

Razlaga 3

Zanka do-while

Pri zanki do-while je pogoj na koncu: telo se izvede najprej, pogoj pa se preveri šele po prvi ponovitvi. Zato se telo izvede vsaj enkrat. Za zaprtim oklepajem pogoja je podpičje.

do {
    telo
} while (pogoj);   // podpičje na koncu

int x = 10;
do {
    System.out.println(x);   // izpiše 10
    x++;
} while (x < 5);             // 11 < 5 ni res: konec

Tipični uporabi sta preverjanje vnosa (uporabnik mora vpisati število vsaj enkrat, preden ga lahko preverimo) in meni, ki se ponavlja, dokler uporabnik ne izbere izhoda. Primer: ponavljamo vnos, dokler število ni štirimestno.

Scanner sc = new Scanner(System.in);
int stevilo;                                     // deklariran PRED zanko, da je viden v pogoju
do {
    System.out.println("Vnesi stirimestno stevilo");
    stevilo = sc.nextInt();
} while (stevilo < 1000 || stevilo > 9999);      // ponavljaj, dokler število ni ustrezno
whiledo-while
kje je pogojna začetkuna koncu
najmanj ponovitev01
podpičje za pogojemneda
tipična uporabaponavljanje, ki se morda ne izvedevnos, meni, nekaj moramo narediti vsaj enkrat

Doseg: spremenljivka, deklarirana v telesu zanke do-while, v pogoju ni vidna. Če jo uporabljaš v pogoju, jo deklariraj pred zanko (kot stevilo zgoraj). Pogoj pri do-while pove, kdaj zanka nadaljuje, ne kdaj se konča.

Razlaga 4

Katero zanko izbrati in pretvorba med zankami

Vsako zanko lahko zapišemo z vsako drugo. Maturitetne naloge pogosto zahtevajo: »Zapišite isto kodo brez zanke for« ali »pretvorite zanko do-while v for«. Pravilo za pretvorbo for v while:

for (A; B; C) {          // zanka for
    S
}

A;                       // enakovredna zanka while
while (B) {
    S
    C;
}

Isto štetje od 0 do 4 z vsemi tremi zankami:

for
for (int i = 0; i < 5; i++) {
    System.out.print(i);
}
while
int i = 0;
while (i < 5) {
    System.out.print(i);
    i++;
}
do-while
int i = 0;
do {
    System.out.print(i);
    i++;
} while (i < 5);

Vse tri zanke izpišejo 01234.

Pozor pri do-while: zapisa z while in do-while sta enakovredna samo, če je pogoj pred prvo ponovitvijo izpolnjen. Če pogoj ni izpolnjen, zanka while telesa ne izvede, do-while pa ga izvede enkrat. Pri pretvorbi for v do-while zato pogoj pogosto preverimo še pred zanko (if).

Razlaga 5

Gnezdene zanke

Zanka je navaden stavek, zato jo lahko zapišemo znotraj druge zanke. Temu rečemo gnezdenje. Za vsako ponovitev zunanje zanke se notranja zanka izvede v celoti. Tako obdelamo vrstice in stolpce: zunanja zanka šteje vrstice, notranja stolpce.

for (int i = 1; i <= 3; i++) {       // vrstice
    for (int j = 1; j <= 4; j++) {   // stolpci
        System.out.print("*");
    }
    System.out.println();            // nova vrstica
}
// ****
// ****
// ****
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= i; j++) {   // meja je odvisna od i
        System.out.print("*");
    }
    System.out.println();
}
// *
// **
// ***

Skupno število ponovitev notranjega telesa je pri pravokotniku 3 · 4 = 12, pri trikotniku pa 1 + 2 + 3 = 6. Če meja notranje zanke ni odvisna od zunanjega števca, ponovitve množimo, sicer jih seštejemo po vrsticah.

Mesto stavka println: System.out.print stoji v notranji zanki, System.out.println() pa za notranjo zanko in znotraj zunanje, da se vsaka vrstica zaključi.

Pri nalogah »kaj izpiše« gnezdena zanka: izpiši vrednosti i in j po vrsticah (i = 1: j = 1, 2, 3 …). Tako vidiš, kdaj se notranja zanka ne izvede (npr. ko je pogoj j < i pri i = 1 že neresničen).

Razlaga 6

Stavka break in continue

Včasih zanke ne želimo izvesti do konca. Stavek break zapusti zanko (najbližjo, v kateri stoji), program pa se nadaljuje za zanko. Stavek continue preskoči preostanek trenutne ponovitve in nadaljuje z naslednjo. Pri for se pred preverjanjem pogoja izvede še korak (i++), pri while in do-while skoči izvajanje takoj na pogoj.

break: iskanje najmanjšega delitelja
int n = 91;
for (int d = 2; d < n; d++) {
    if (n % d == 0) {
        System.out.println(d);   // 7
        break;                   // delitelj najden, zanko lahko končamo
    }
}
continue: izpis lihih števil
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;                // sodo število preskočimo
    }
    System.out.print(i + " ");   // 1 3 5 7 9
}

Neskončna zanka z izhodom. Zanko while (true) poznamo kot zanko, ki jo prekine šele break. Uporabna je, kadar vnaprej ne vemo, kdaj bo konec (npr. meni, ki se ponavlja, dokler uporabnik ne izbere izhoda).

Stavek break prekine samo najbolj notranjo zanko ali stavek switch. Metodo pa zapusti stavek return.

for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == 2) {
            break;               // prekine samo notranjo zanko
        }
        System.out.println(i + " " + j);
    }
}
// izpis: 1 1, 2 1, 3 1

Past pri while: continue skoči na pogoj in preskoči tudi spremembo števca, če je ta na koncu telesa. Pri int i = 0; while (i < 5) { if (i == 2) continue; i++; } se i nikoli ne poveča preko 2 in zanka je neskončna. Pri zanki for te težave ni, ker se korak vedno izvede.

Delo s števkami števila

Zadnja števka števila je n % 10, število brez zadnje števke pa n / 10. Zanka teče, dokler od števila kaj ostane.

int n = 472;
int vsota = 0;
while (n > 0) {
    vsota += n % 10;     // 2, nato 7, nato 4
    n /= 10;             // 47, nato 4, nato 0
}
System.out.println(vsota);   // 13

Praštevilo in Evklidov algoritem

Praštevilo: deljitelji do √n
static boolean jePrastevilo(int n) {
    if (n < 2) return false;
    for (int d = 2; d * d <= n; d++) {
        if (n % d == 0) {
            return false;   // našli smo delitelj
        }
    }
    return true;
}
Največji skupni delitelj (48, 18)
int a = 48, b = 18;
while (b != 0) {
    int ostanek = a % b;    // 12, nato 6, nato 0
    a = b;
    b = ostanek;
}
System.out.println(a);      // 6

Število n ni praštevilo, če ima delitelj med 2 in √n. Preverjamo d * d <= n, ker bi imel vsak večji delitelj že par, manjši od √n, in bi ga našli prej. Pri Evklidovem algoritmu zamenjamo (a, b) z (b, a % b), dokler b ni 0; takrat je največji skupni delitelj enak a. Najmanjši skupni večkratnik je a / nsd * b.

Zaporedja

Pri zaporedjih si moramo zapomniti prejšnji člen (ali dva). Člen zaporedja računamo v zanki, nato spremenljivke »premaknemo«. Kadar vnaprej ne vemo, koliko členov bo (npr. zaporedje, ki se konča, ko pride do 1), uporabimo zanko while. Pri računanju z decimalnimi števili ne pozabi na tip double: 1 / 3 je pri celih številih 0, 1.0 / 3 pa 0,333…

Pri izračunu fakultete ali potence uporabi tip long: že 13! ne gre več v tip int. Začetna vrednost produkta je vedno 1, ne 0.
