Booleova algebra in minimizacija

0 / točk ·

Uvod in cilji

Isto logično funkcijo lahko zapišemo na veliko načinov. Nekateri zapisi potrebujejo veliko vrat, drugi malo. Minimizacija (poenostavljanje) poišče najkrajši zapis: manj vrat pomeni cenejše, hitrejše in zanesljivejše vezje z manjšo porabo. Za poenostavljanje imamo dve orodji: Booleovo algebro (računanje s pravili) in Veitchev diagram (grafično iskanje skupin).

Primer: glasovanje »večina od treh« Iz tabele dobimo Y = A·B·C + A·B·C + A·B·C + A·B·C: 4 vrata IN s tremi vhodi, 3 negatorji, vrata ALI s štirimi vhodi in 12 literalov.
Po poenostavitvi: Y = A·B + A·C + B·C: 3 vrata IN z dvema vhodoma in ena vrata ALI, 6 literalov. Tabela je enaka.

Cilji

Sklopi

Kako poteka vaja

  1. Preberi teorijo in jo preizkusi v simulaciji. Pri vsakem pravilu lahko enakost preveriš s tabelo.
  2. Pri nalogah z vpisom izraza piši: negacija ¬A ali A', IN · ali skupaj (AB), ALI +, NAND ↑, NOR ↓. Pod poljem so tipke za vse znake.
  3. Če naloga zahteva najkrajši zapis, mora biti izraz pravilen in mora imeti najmanj literalov (spremenljivk v zapisu).

Točkovanje

  • Lahka naloga je vredna 1 točko, srednja 2 točki, težka 3 točke.
  • Namig odbije 50 % točk naloge. Ogled rešitve prinese 0 točk.
  • Ko pritisneš »Preveri«, se odgovor zaklene. Izjema: če izraza ni mogoče prebrati (npr. manjka zaklepaj), te opozorimo in ga lahko popraviš.

Postulati Booleove algebre

Postulati so osnovna pravila, ki jih ne dokazujemo, ampak jih vzamemo kot dogovor. Iz njih izpeljemo vse ostalo. Booleova algebra pozna samo vrednosti 0 in 1 ter operacije · (IN), + (ALI) in negacijo.

PostulatOblika z ALIOblika z IN
P1 zaprtostrezultat operacije je spet 0 ali 1
P2 nevtralni elementA + 0 = AA·1 = A
P3 komutativnost (zamenjava)A + B = B + AA·B = B·A
P4 distributivnostA + B·C = (A + B)·(A + C)A·(B + C) = A·B + A·C
P5 komplementA + A = 1A·A = 0

Načelo dualnosti

Vsako pravilo ima dualno obliko: zamenjamo + in · ter 0 in 1. Če velja eno, velja tudi drugo. Zato so v tabeli postulati v parih.

A + 0 = A  ⟷  A·1 = A     A·(B + C) = A·B + A·C  ⟷  A + B·C = (A + B)·(A + C)
Pozor, ni kot v matematiki: druga oblika distributivnosti, A + B·C = (A + B)·(A + C), pri navadnih številih ne velja (2 + 3·4 ≠ 5·6). V Booleovi algebri velja, kar lahko preveriš s tabelo v simulaciji.

Teoremi Booleove algebre

Teoremi so pravila, ki jih dokažemo s postulati ali s pravilnostno tabelo. To so orodja, s katerimi krajšamo izraze.

TeoremOblika z ALIOblika z IN
T1 idempotencaA + A = AA·A = A
T2 dominancaA + 1 = 1A·0 = 0
T3 dvojna negacijaA = A
T4 absorpcijaA + A·B = AA·(A + B) = A
T5 absorpcija negacijeA + A·B = A + BA·(A + B) = A·B
T6 asociativnost(A + B) + C = A + (B + C)(A·B)·C = A·(B·C)
T7 združevanje sosedovA·B + A·B = A(A + B)·(A + B) = A
T8 konsenzA·B + A·C + B·C = A·B + A·C
T9 De MorganA + B = A·BA·B = A + B

Dokaz s postulati

T4 absorpcija: A + A·B = A A + A·B = A·1 + A·B (P2) = A·(1 + B) (P4) = A·1 (T2) = A (P2).
T7 združevanje sosedov: A·B + A·B = A A·B + A·B = A·(B + B) (P4) = A·1 (P5) = A (P2). To pravilo je temelj Veitchevega diagrama.

Dokaz s tabelo

Dva izraza sta enaka, če imata v vseh vrsticah tabele enak izhod. To je vedno mogoče preveriti, pri treh spremenljivkah je vrstic samo osem.

De Morganova izreka

De Morganova izreka povesta, kako negacija »preide« skozi oklepaj: negacija zamenja IN z ALI (in obratno) in negira vsako spremenljivko.

A·B = A + B     A + B = A·B

Izreka veljata za poljubno število spremenljivk: A·B·C = A + B + C.

Pomen za vezja

  • Vrata NAND so enaka vratom ALI z negiranimi vhodi.
  • Vrata NOR so enaka vratom IN z negiranimi vhodi.

Zato lahko krogce »premikamo« z izhoda na vhode in obratno. Na tem temelji realizacija z vrati NAND in NOR.

Negacija dolgega izraza

Primer A·B + C = A·B·C (De Morgan za +) = (A + B)·C (De Morgan za ·) = (A + B)·C (dvojna negacija).
Primer iz vsakdana, alarm »vse v redu«: lučka OK sveti, ko ni odprto nobeno okno: OK = O1 + O2 + O3. Po De Morganu je to O1·O2·O3: vsa okna so zaprta. Oba zapisa opisujeta isto, vezje pa je lahko eno samo vrata NOR.

Algebrsko poenostavljanje

Pri algebrskem poenostavljanju izraz korak za korakom preoblikujemo s postulati in teoremi, dokler ga ne moremo več skrajšati. Vsak korak mora ohraniti tabelo.

Postopek

  1. Če je nad oklepajem črta, jo razreši z De Morganom.
  2. Poišči člene, ki imajo skupne faktorje, in jih izpostavi (P4).
  3. V oklepaju poišči X + X = 1 ali 1 + X = 1.
  4. Uporabi absorpcijo: člen, ki že vsebuje krajši člen, odpade (A + A·B = A).
  5. Člen lahko tudi podvojiš (A = A + A), če ga potrebuješ v dveh skupinah.
Primer 1 A·B·C + A·B·C = B·C·(A + A) = B·C·1 = B·C
Primer 2 A·B + A·B·C + A·B = A·B·(1 + C) + A·B = A·B + A·B = A·(B + B) = A
Primer 3: večina od treh (podvajanje člena) ABC + ABC + ABC + ABC. Člen ABC trikrat zapišemo (T1) in ga združimo z vsakim od ostalih:
(ABC + ABC) + (ABC + ABC) + (ABC + ABC) = BC + AC + AB
Primer 4: z De Morganom A·B·B = (A + B)·B = A·B + B·B = A·B + 0 = A·B

Algebrska pot je pri večjih izrazih težavna, ker ni vedno jasno, katero pravilo uporabiti. Zato uporabljamo Veitchev diagram, ki skupne člene pokaže grafično.

Veitchev diagram

Veitchev diagram je pravilnostna tabela, preurejena v pravokotnik. Vsaka celica je ena vrstica tabele. Ob robu so črte spremenljivk: pod črto je spremenljivka 1, kjer črte ni, je 0. Celice so razvrščene tako, da se sosednji celici razlikujeta natanko v eni spremenljivki.

2 spremenljivki: 4 celice

3 spremenljivke: 8 celic

4 spremenljivke: 16 celic

Številka v kotu celice je številka vrstice tabele (v zvezek je ni treba pisati).

Kako diagram narišeš v zvezek

  1. Nariši pravokotnik: 2 × 2 celici za dve spremenljivki, 2 × 4 za tri, 4 × 4 za štiri.
  2. A: črta zgoraj nad levo polovico stolpcev.
  3. B: črta levo ob zgornji polovici vrstic.
  4. C (tri ali štiri spremenljivke): črta spodaj pod srednjima stolpcema.
  5. D (štiri spremenljivke): črta desno ob srednjih dveh vrsticah.
  6. V celico vpišeš vrednost iz tiste vrstice tabele, pri kateri so pod črto ravno spremenljivke z vrednostjo 1. Primer: celica pod črtama A in C, levo od nje ni črte B, desno je črta D, je A = 1, B = 0, C = 1, D = 1, torej vrstica 1011 = 11.

Sosednost

  • Sosednji sta celici levo in desno ter zgoraj in spodaj, ne pa diagonalno.
  • Levi in desni rob sta sosednja, prav tako zgornji in spodnji. Diagram si predstavljaj, kot da je zvit v valj.
  • Štiri vogalne celice pri štirih spremenljivkah so vse med sabo sosednje: v vseh je C = 0 in D = 0.

Zakaj deluje

Dve sosednji enici se razlikujeta v eni spremenljivki, zato po pravilu T7 (X·Y + X·Y = X) ta spremenljivka izpade. Skupina dveh celic izloči eno spremenljivko, skupina štirih dve, skupina osmih tri.

Večina od treh: Y = A·B + A·C + B·C

Vogali: Y = C·D

Minimizacija z Veitchevim diagramom

Postopek vodi do najkrajše vsote produktov. Imenujemo jo tudi minimalna PDNO (popolna disjunktivna normalna oblika, ki jo skrajšamo).

Postopek po korakih

  1. Iz tabele ali enačbe vpiši enice v ustrezne celice (številka v kotu pove vrstico).
  2. Enice združi v skupine po 1, 2, 4, 8 ali 16 celic (vedno potenca števila 2). Skupina je pravokotnik sosednjih celic, lahko gre čez rob.
  3. Skupine naj bodo čim večje. Vsaka enica mora biti v vsaj eni skupini, skupine se smejo prekrivati.
  4. Uporabi čim manj skupin: skupina, katere vse enice so že pokrite z drugimi, je odveč.
  5. Iz vsake skupine zapiši produkt spremenljivk, ki se v skupini ne spreminjajo: pri vrednosti 1 spremenljivko zapišeš, pri 0 jo negiraš.
  6. Produkte seštej.
Primer: Y = 1 v vrsticah 0, 2, 5, 7, 8, 10, 13, 15
Spodnja vrstica (0, 2, 8, 10): B = 0 in D = 0 se ne spreminjata → B·D. Druga vrstica (5, 7, 13, 15): B = 1 in D = 1 → B·D. Y = B·D + B·D. To je EXNOR spremenljivk B in D.

Pogoste napake

  • Skupina treh ali šestih celic ni dovoljena.
  • Diagonalni celici nista sosednji.
  • Pozabljena skupina čez rob: celici v prvem in zadnjem stolpcu sta sosednji.

Nepomembna stanja (X)

Včasih nekaterih kombinacij vhodov nikoli ne bo. Pri števki v kodi BCD vzorci 1010 do 1111 ne obstajajo. V diagram vpišemo X in jih po potrebi štejemo kot enice, če s tem dobimo večjo skupino.

Primer: lučka »števka je 5 ali več« za kodo BCD (ABCD)
Z X dobimo Y = A + B·D + B·C. Brez X bi bil izraz precej daljši.

Skupine ničel

Enako lahko združujemo ničle. Iz skupine ničel zapišemo vsoto: spremenljivko z vrednostjo 0 zapišemo, z 1 jo negiramo. Vsote zmnožimo in dobimo minimalni produkt vsot. Kadar je ničel malo, je ta zapis krajši.

Realizacija z vrati NAND in NOR

Minimalni izraz najprej narišemo z vrati IN in ALI (dve ravni). Nato ga z dvojno negacijo in De Morganom pretvorimo v vezje samo iz vrat NAND. Tako potrebujemo samo eno vrsto čipov, na primer 7400.

Vsota produktov → NAND-NAND

  1. Zapiši minimalno vsoto produktov: Y = A·B + C·D.
  2. Celoten izraz dvakrat negiraj: Y = A·B + C·D.
  3. Spodnjo negacijo razreši z De Morganom: Y = A·B·C·D.
  4. Vsak X·Y je ena vrata NAND: Y = (A ↑ B) ↑ (C ↑ D).

Pravilo na kratko: vsa vrata IN in ALI zamenjaš z vrati NAND. Spremenljivka, ki gre sama v vrata ALI, se mora negirati (ena vrata NAND kot negator).

Produkt vsot → NOR-NOR

Dualno velja za produkt vsot: Y = (A + B)·(C + D) = A + B + C + D = (A ↓ B) ↓ (C ↓ D). Vsa vrata ALI in IN zamenjaš z vrati NOR.

Primer: večina od treh z vrati NAND Y = A·B + A·C + B·C = (A ↑ B) ↑ (A ↑ C) ↑ (B ↑ C), kjer so zadnja vrata NAND s tremi vhodi. Skupaj štiri vrata NAND, en čip 7400 in en 7410 (3 × NAND s tremi vhodi).
Primer iz vsakdana, krmilje stiskalnice: pri gradnji krmilja na prototipni ploščici imaš v predalu samo čipe 7400. Z vrati NAND zgradiš vsako funkcijo in ti ni treba čakati na naročilo drugih čipov.

Izziv: pri funkciji Y = A + B·C (NAND) poišči, zakaj se je pojavil negator pri spremenljivki A.
